# personal/ - 个人学习过程笔记

> **规则**：这里只放"过程"，不放"产出"。
> 写不出名字的困惑、半懂不懂的猜测、读了三遍才懂的细节，**都写在这里**。

## 命名规范

```
YYYY-MM-DD-<主题>.md
```

例：
- `2026-07-19-重置与真学习.md`
- `2026-07-19-agent-类构造初探.md`
- `2026-07-20-middleware-钩子链为什么这么设计.md`

## 笔记模板（低阻力，15 分钟一篇）

```markdown
## YYYY-MM-DD | 主题

**读了什么**：`src/.../path.py:LINE-LINE`

**我看懂了**：
- ...

**我没搞懂**：
- ...

**我的猜测**：
- ...

**明天要看**：
- ...
```

## 跟 learning-map/ 的关系

- `personal/` 是**过程**（仅自己可见）
- `learning-map/` 是**目标**（可分享，但标了"未经验证"）
- 等 `personal/` 笔记积累到能"拼成图"，再**提升**到 `learning-map/` 正式版

## 跟 phase-X/ 的关系

- 未来 Phase 2 / Phase 3 真正的"成果"会放在 `notes/phase-2/` `notes/phase-3/`
- 这些 phase-X 文档**必须基于 personal/ 笔记写**，不能直接由 AI 生成
