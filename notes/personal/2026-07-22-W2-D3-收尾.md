### 今日最大收获（3 个）

#### 1. **schema-driven 管道**（这是今天最值钱的洞察）

```
Pydantic SummarySchema (Python 类)
    ↓ (Pydantic 自动生成)
JSON Schema (字典)
    ↓ (作为 tool 参数)
Function Calling (LLM API 原生)
    ↓ (LLM 严格按 schema 输出)
Pydantic 解析 (res.content = dict)
    ↓ (**res.content)
模板填充 (cfg.summary_template.format(...))
```

**每个环节都是"标准接口"**——换 LLM、换 schema、换模板，**这条管道不动**。

**对比 W1 的"AI 整理的图"**：那时候我把 AgentScope 画成"4 层架构 + 6 大原语"——**画的是结构**，看不到这种**跨协议层的"对接"细节**。今天从 `_compress_context_impl` 里看到了**框架的真正精巧之处**。

#### 2. **3 级降级**（Graceful Degradation）

```
1. 理想配置 (reserve 10%)
   ↓ 失败
2. 激进配置 (reserve 0%)
   ↓ 还失败
3. 暴力配置 (逐个丢最早消息)
```

这是分布式系统的标准模式。**昨天学的"在线"今天在学到的"降级策略"里得到验证**。

#### 3. **异步原子性**（asyncio.shield）

`apply_state_change` 阶段**不能被打断**——否则 state 半更新，agent 行为错乱。

**这是"事务"概念在异步上下文的实现**——和数据库的 ACID 一个思想。

### 今日 1 个"错得有价值"

这个过程教会我 2 件事：
1. **"独立数学" vs "工程现实"是两件事**——理论上独立，实践上必须满足约束

**这比"答对"更有价值**——以后遇到任意 2 个 ratio，**先问"它们是独立概念还是同一概念"**，别靠直觉。
