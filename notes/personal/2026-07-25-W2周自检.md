## 3. 5 大核心成果（按价值排序）

### ① Q5 真 bug 闭环（W2 最重要）

**完整流程**：怀疑（W2-D4）→ 验证（W2-D5）→ issue 草稿 4 轮优化 → 提交到 agentscope-ai/agentscope #2166。

**位置**：`src/agentscope/agent/_agent.py:705`

**根因**：`_close_unfinished_tool_calls` 的设计假设（ALLOWED = START 已 emit）和 `_execute_tool_call` 状态机（external tool 活跃期 = ALLOWED + SUBMITTED）对不齐。

**修复**：`if call_block.state not in (ALLOWED, SUBMITTED):`

### ② reentrant protocol 概念（W2 最有洞察）

**核心**：HITL = 多步表单/软件安装向导 = 可重入协议。

**关键属性**：
1. State 持久化
2. Resume point 明确
3. Caller 可观测

**为什么 distributed system 必须 reentrant**：**不 reentrant = 线程死锁 = 不能 scale**。

### ③ 状态机视角（tool call 5 态）

```
PENDING → ASKING → ALLOWED → (SUBMITTED) → FINISHED
                  ↓ DENY
                  ERROR
```

**3 类正交输入**（6 种 input 的根因）：同步 / 异步 / 轮询。

**3 种结束状态 = 3 种责任归属**：自然 / 限制 / 中断。

### ④ ReAct 核心循环（_reply_impl + _reasoning_impl）

**完整看懂 2 个核心方法**：
- `_reply_impl` line 732-991：ReAct 状态机
- `_reasoning_impl` line 1291-1442：LLM 调用 + 响应解析

**关键设计**：
- 6 种 input 异步协议
- 3 段 ReAct 循环：reasoning → acting → observation
- 双模式响应（asyncgen / ChatResponse）
- Fail fast on empty response
- Thinking-only = intermediate state

### ⑤ 3 档反馈方法论（W2 最有用方法）

```
✅ 已掌握 —— 能解释 + 能应用
⚠️ 浅     —— 知道是什么，不知道为什么
❌ 缺     —— 不知道是什么
```

**这是 W2 最有用的方法论调整**——**从"放水表扬"升级到"严格评分"**。
